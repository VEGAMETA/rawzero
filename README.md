<h1 align="center">RawZero</h1>

<p align="center">
  Камера для Android без нейросетей: хорошая фотография из хорошего железа.<br>
  Один RAW-кадр → детерминированный классический конвейер → один JPEG.
</p>

---

## Зачем

Штатные камеры телефонов давно не «снимают», а дорисовывают: многокадровая склейка, нейросетевое шумоподавление, «акварель» вместо текстуры, пересушенная резкость. RawZero берёт сырой кадр с сенсора и проявляет его сам, классическими алгоритмами, которые можно прочитать и проверить. Картинка при этом выглядит так, как её показывало превью.

- **Никакого ML.** Ни шумодава на нейросетях, ни сегментации, ни «AI-сцен», ни бьютификации.
- **Один кадр** (кроме явного ночного режима). Никаких HDR-склеек за спиной у пользователя.
- **Не греется.** Превью идёт через аппаратный ISP; RAW обрабатывается только в момент съёмки.
- **Все камеры.** Приложение само находит линзы, включая скрытые прошивкой (см. ниже).

## Режимы

| Режим | Что делает |
|---|---|
| **Цифровой** (по умолчанию) | Наш конвейер: шумоподавление в RAW; тон, баланс белого и насыщенность подогнаны под кадр превью в момент спуска. Детали и зерно — свои, без «мыла» ISP. |
| **RAW** | «Process Zero»: минимальный конвейер без шумодава и локальных операций, фиксированная кривая + DNG рядом. |
| **Экран** | Ровно то, что показывал экран: полноразмерный JPEG штатного ISP, перекрашенный по кадру превью (у ISP превью и снимок настроены по-разному). В галерее выглядит так же, как превью перед спуском. |
| **Скрин** | Кадр самого видоискателя в полном разрешении потока превью (до 1440×1920): как скриншот, чисто, без пересушенной резкости полноразмерного JPEG камеры (особенно заметно при зуме). |
| **Ночь** | Серия из 8 RAW-кадров, выравнивание и склейка по методу HDR+ (Hasinoff 2016): шум падает примерно в √8 раз, движущиеся объекты не двоятся. Затем «Цифровой». Держать телефон неподвижно ~1–5 с. |

Зум щипком на любой камере (двойной тап — 1×/2×): превью и JPEG ISP приближает камера, RAW наш конвейер обрезает по центру на ту же долю, без «дорисовки» пикселей. Вспышка: выкл / при съёмке / всегда (через фонарик, автоэкспозиция подстраивается под его свет). Режим и камера запоминаются.

Ручные настройки (всё «авто» по умолчанию): экспозиция (EV), выдержка, ISO, фокус, баланс белого в кельвинах. Выдержка — до предела сенсора: на Xiaomi 14 до 30–60 с через вендорский механизм Qualcomm; превью при этом остаётся плавным (30 fps) и показывает итоговую яркость. Во время длинной выдержки идёт обратный отсчёт.

Один снимок на кадр: `Pictures/RawZero/` (фронталка отражена как в превью, задние — как есть). DNG — только в режиме RAW: `Pictures/RawZero/DNG/`.

## Установка

Готовые APK — в [Releases](https://github.com/VEGAMETA/rawzero/releases).

| APK | Для кого |
|---|---|
| `RawZero` (`dev.vegameta.rawzero`) | Любой телефон. Xiaomi 14: все камеры. |
| `RawZero S` (`com.samsung.android.scan3d`) | **Samsung**: системный сервис камер показывает телевики только пакетам из белого списка, и этот вариант в него попадает. Стоит попробовать и на других брендах, если обычный вариант нашёл не все линзы. |

На Xiaomi/HyperOS для установки через adb нужен пункт «Установка через USB» в параметрах разработчика.

## Камеры: что удалось открыть

При первом запуске приложение перебирает ID камер 0..255 и физические линзы внутри логических камер, реально открывает каждую и проверяет нужную конфигурацию потоков, затем кэширует результат до следующего обновления прошивки (кнопка «Пересканировать камеры» — в настройках).

| Устройство | W | UW | Теле | Теле 2 | Фронт |
|---|---|---|---|---|---|
| Xiaomi 14 (HyperOS 3) | 23 мм RAW | 14 мм RAW | 60 мм RAW | — | RAW |
| Samsung S21 Ultra (`RawZero S`) | 24 мм RAW | 14 мм RAW | 70 мм RAW | 238 мм RAW | только ISP |

Подробности и измерения — в [`CLAUDE.md`](CLAUDE.md) и `tools/reports/`. Например: RAW из стокового Pro-режима Xiaomi на деле многокадровый (шум в ~120 раз ниже, чем у одиночного кадра при том же ISO), а HAL Xiaomi сообщает, что коррекция виньетирования применена, хотя это не так.

## Конвейер

```
RAW_SENSOR ─► уровни ─► [шумодав] ─► виньетирование ─► горячие пиксели ─► баланс белого
           ─► демозаик (Malvar–He–Cutler) ─► цвет (DNG: матрицы по CCT, ForwardMatrix, Bradford)
           ─► [WB + тон под превью] / фиксированная кривая ─► sRGB ─► JPEG
```

- **Шумоподавление** (`core/src/denoise.rs`) — в RAW до демозаика, где шум ещё независим. Ячейка Байера раскладывается на яркость, две цветоразности и разность зелёных; модель шума Poisson–Gaussian оценивается по самому кадру; яркость — блоки Уолша–Адамара 8×8 (жёсткий порог + эмпирический Винер, как двухпроходный BM3D, но без поиска блоков); цвет — guided filter по очищенной яркости; часть зерна оставляется намеренно.
- **Подгонка под превью** (`core/src/look.rs`) — баланс белого по средним тонам, глобальная монотонная тоновая кривая (сопоставление гистограмм яркости) и насыщенность относительно кадра превью в момент спуска. Только глобальные преобразования: вид экрана заимствуется, детализация — нет.
- **Детерминизм**: одинаковый вход даёт побитово одинаковый JPEG при любом числе потоков.
- **Скорость**: 0.7–1.3 с на кадр 12 Мп на Snapdragon 8 Gen 3 (CPU).

## Сборка

Нужны Rust (stable), [`cargo-ndk`](https://github.com/bbqsrc/cargo-ndk), Android SDK 36 + NDK, JDK 17+.

```sh
cargo test --workspace                       # тесты конвейера
cargo run -p rawzero-desktop --release -- photo.dng -o out.jpg            # Process Zero
cargo run -p rawzero-desktop --release -- photo.dng --ref isp.jpg -o out.jpg  # Классика

./gradlew assembleRawzeroDebug     # RawZero    (Gradle сам собирает Rust через cargo-ndk)
./gradlew assembleScan3dDebug      # RawZero S
```

Python-инструменты (`tools/`) запускаются через uv:

```sh
uv run --no-project --with rawpy --with numpy tools/raw_noise.py a.dng b.dng   # одиночный ли это кадр
uv run --no-project --with rawpy --with numpy tools/flatfield.py wall.dng       # виньетирование
adb shell dumpsys media.camera > dump.txt && uv run --no-project tools/camera_dump.py dump.txt
```

## Структура

```
core/        Rust: весь конвейер, без зависимостей от Android, с тестами
jni-bridge/  Rust: тонкий JNI-слой (единственное место с unsafe)
desktop/     Rust CLI: DNG → JPEG для отладки и сравнения (читатель DNG свой, вкл. lossless JPEG)
app/         Kotlin: Camera2, интерфейс, сохранение; без обработки пикселей
tools/       Python: проверки шума, виньетирования, разбор dumpsys
```

## Ограничения

- Фронтальная камера Samsung S21U не отдаёт RAW ни под каким ID — снимает только ISP.
- Samsung вычитает уровень чёрного в HAL и обрезает отрицательные значения: в тенях возможен лёгкий пурпурный сдвиг.
- На выдержках длиннее 1 с через вендорский путь Qualcomm HAL сам выбирает ISO.
- Ночной режим склеивает 8 кадров с короткой выдержкой (≤1/8 с); в почти полной темноте этого может не хватить.
